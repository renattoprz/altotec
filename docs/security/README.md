# Seguridad y privacidad de AltoTec

Este directorio es el sistema de gestión de seguridad del proyecto. Cada control
está implementado en el código o en la operación y se puede verificar.
Marco: SOC 2 (Criterios de Servicios de Confianza), ISO/IEC 27001:2022 (Anexo A),
ISO/IEC 27701 y Ley N.° 29733 de Protección de Datos Personales (Perú).
